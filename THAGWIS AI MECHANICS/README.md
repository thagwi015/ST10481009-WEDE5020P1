# THAGWIS AI MECHANIC — Part 3
## Live website
https://silly-biscuit-0bb1a0.netlify.app
## Project overview
This is a multi-page website for THAGWIS AI MECHANIC. It helps visitors explore vehicle services, search and sort the service list, submit a service enquiry, and find the Pretoria and Johannesburg branches.

## Pages
- `index.html` — Home
- `about.html` — About the workshop
- `services.html` — Service listings
- `enquiry.html` — Service enquiry form
- `contact.html` — Contact details and branch map

## Technologies
- HTML for page structure and form
- CSS for layout, styling, and responsive design
- JavaScript for search, sorting, image viewing, and form validation
- Leaflet and OpenStreetMap for the interactive map

## How to view the website
Open `index.html` in a web browser. An internet connection is needed for the map tiles. The forms use the visitor’s email application; they do not send data to a website server.
